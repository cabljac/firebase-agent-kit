# Hacking

- A Hacker or a character with a Deck adds +2 to the roll. Everyone else adds +0.
- A door or a terminal: rollDice 1d20, 10 or more opens it.
- A vault or a security system is a risky action: call attemptRiskyAction with difficulty 15. On a failure, the alarm sounds and station security arrives.
- An ICE trap on a natural 1 deals 1d6 damage: call updateCharacter.
