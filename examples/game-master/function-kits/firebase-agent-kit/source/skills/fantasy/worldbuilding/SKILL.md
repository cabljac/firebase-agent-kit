# Worldbuilding

The 150-word limit does not apply here. Write a short gazetteer in this order:

1. Four regions, each with a name, a landscape and one danger.
2. Three factions, each with a goal and a rival.
3. The starting village, with three people the hero can talk to.
4. A rumour that starts the first quest.

Then call getCharacter. If the player has no character, ask for a name and a class.
